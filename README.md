## 🍄 Myxelium-Corp — Mon Organisation

> [**github.com/Myxelium-Corp**](https://github.com/Myxelium-Corp)

Plateforme de multi-agents IA biomimétique — orchestration en essaim, inspirée des réseaux mycéliens.

| Couche | Composant | Rôle |
|--------|-----------|------|
| 🧠 Cerveau | **NEXUS** (Fastify) | Coordinateur central, routeur d'agents |
| 🐝 Pool | **HIVE** (LangGraph) | Gestion du cycle de vie des agents |
| ⚡ Exécution | **SWARM** (Redis pub/sub) | Traitement parallèle distribué |
| 📡 Protocole | **MUL** (emoji+markdown) | Langage universel inter-agents |
| 💾 Mémoire | **FirebaseCheckpointer** | État persistant avec HiTL checkpoints |
